# Legacy documentation

This directory preserves documentation that pre-dates the flattened repository
layout introduced in BEOL_TDDB_V3.

* `Wafer Mapping Tool Guide Updated July 27.pdf` is the original operator and
  model guide.
* `Wafer Mapping Tool Guide Updated July 27.docx` is its editable source.

The historic guide may refer to `BEOL_TDDB_Physical_Models_Chris_Fork/` as the
project root. That directory no longer exists: all code, data, configs, and
scripts now live directly at this repository root. Consult the root `README.md`
for the current layout and commands.

`PROJECT_GUIDE.md` is the current maintained Markdown guide. It preserves the
legacy physics workflow and documents the newer spatial ML backends.
